# Hungry Hare 🍔

A modern full-stack food delivery web application inspired by Uber Eats and Tesco online ordering systems.

---

# 📌 Project Overview

Hungry Hare is a responsive food ordering platform developed using:

- Python Flask
- SQLite Database
- Tailwind CSS
- HTML5
- JavaScript

The application allows users to:

- Browse food categories
- View menu items
- Add items to cart
- View total cart amount
- Access payment and careers pages
- Use responsive navigation menu

---

# 🚀 Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend Logic |
| Flask | Web Framework |
| SQLite | Database |
| HTML5 | Structure |
| Tailwind CSS | Styling |
| JavaScript | Cart Functionality |
